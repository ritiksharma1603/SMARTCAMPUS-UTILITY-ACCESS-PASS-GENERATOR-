# SMARTCAMPUS-UTILITY-ACCESS-PASS-GENERATOR-
This is a Python based mini project that generates a 
SMARTCAMPUS-UTILITY-ACCESS-PASS invoice based on user 
details and selected facilities.

This program calculates : 
- Access Pass Fee 
- Merit/Service Discount
- Parking Fee
- Student Peak Surcharge
- Electricity Bill
- Total Monthly Payable Amount
 
Also this code revolves around the concept of Nested Conditional Statement.....
